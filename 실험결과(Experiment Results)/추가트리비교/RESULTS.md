# Random Forest · XGBoost 추가 비교

기존 모델과 동일한 입력 열, 참가자 단위 5개 fold, 최종 평가 행을 사용했다. Random Forest의 기존 교차검증 점수를 재현했다. XGBoost CPU 3.2.0은 학습 fold 내에서 설정을 탐색했다. 각 후보를 전체 Train으로 다시 학습한 후 기존 평가 세트에서 점수를 계산했다. 최종 평가 세트를 재사용한 이번 결과는 사후 비교에 해당한다.

| 평가 | 기준선 | MLP | Random Forest | XGBoost |
|---|---:|---:|---:|---:|
| A 내부 교차검증 (분) | 31.71 | **29.07** | 31.79 | 29.29 |
| A MeLiDos 최종 (분) | 40.91 | 38.14 | 41.45 | **37.89** |
| A 국내 마지막 7일 (분) | **20.06** | 20.25 | 25.25 | 20.59 |
| A 국내 전체 (분) | **21.21** | 21.31 | 26.28 | 21.47 |
| B 내부 교차검증 (점) | 0.822 | **0.778** | 0.779 | 0.783 |
| B MeLiDos 최종 (점) | 0.750 | 0.700 | **0.692** | 0.694 |

모든 수치는 참가자별 평균 절대 오차를 다시 평균한 값이다. A에서 XGBoost와 MLP의 MeLiDos 최종 점수 차이는 −0.24분이며, 참가자 단위 95% 재표집 구간은 −1.65~+1.11분이다. B에서 Random Forest와 MLP의 차이는 −0.008점이며, 구간은 −0.022~+0.006점이다. 이 비교들로 기존 MLP의 교체를 뒷받침할 만큼 일관된 개선은 확인되지 않았다.

Random Forest는 트리 300개를 사용했다. A의 최대 깊이와 잎의 최소 표본 수는 각각 3과 5, B는 6과 15였다. 선택된 XGBoost는 두 모델 모두 80개 트리와 학습률 0.05를 사용했고, 최대 깊이는 A 1, B 2였다. A의 XGBoost 손실은 절대 오차, B는 제곱 오차를 사용했다.

재실행하려면 기존 평가 환경에 `xgboost-cpu==3.2.0`을 추가하고 상위 폴더에서 `python compare_trees.py`를 실행한다. 상세 점수, 참가자별 비교에 사용한 예측값, 저장된 모델은 이 폴더에 있다.
