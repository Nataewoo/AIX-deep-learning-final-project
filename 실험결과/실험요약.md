# 수면일지 모델 A·B 실험 결과

147명의 MeLiDos 학습 자료에서 참가자 단위 5-fold 교차검증을 진행했다. A와 B 모두 은닉층 16→8, Dropout 0.1, 60 epoch의 MLP가 참가자 평균 MAE가 가장 낮았다. 최종 예측에는 세 시드의 평균을 사용했다. B의 교차검증 결과는 Random Forest와 0.001점 미만 차이가 났다.

## 1. 원본에서 학습 데이터 만들기

팀 패키지의 참가자 분할과 원본 레코드 번호를 유지했다. 원본에서 분 단위 입면 지연과 수면 구간 길이, 1~5점 수면의 질을 다시 계산했다. 수면 구간은 입면부터 최종 기상까지이고 밤중 각성을 포함한다.

| 자료 | 참가자 | 전체 기록 | A 유효 기록 | B 유효 기록 |
|---|---:|---:|---:|---:|
| MeLiDos Train | 147 | 1,020 | 1,007 | 1,001 |
| MeLiDos 최종 평가 | 37 | 262 | 259 | 259 |
| 국내 외부 평가 | 49 | 1,372 | 1,372 | 수면의 질 라벨 없음 |

A는 과거 입면 지연 3건의 중앙값과 건수, 직전 수면 구간 길이, 과거 수면 구간 3건의 중앙값과 건수로 입면 지연을 예측한다. B는 이 5개에 해당 밤의 수면 구간 길이를 추가해 수면의 질을 예측한다. 모든 이력은 예측 대상 밤 이전 기록으로 계산했다. 요일과 취침 시각은 입력에서 제외했다.

## 2. 참가자 단위 교차검증

다음은 각 알고리즘에서 가장 낮은 참가자 평균 MAE다. 기록별 오차를 먼저 사람별로 평균한 뒤, 참가자 전체에 대해 평균했다. 결측 대체와 표준화는 각 fold의 학습 부분에서 적합했다.

| 후보 | A MAE (분) | B MAE (점) |
|---|---:|---:|
| 기준선 | 31.71 | 0.822 |
| Ridge | 32.43 | 0.785 |
| Random Forest | 31.79 | 0.779 |
| Gradient Boosting | 29.26 | 0.783 |
| MLP | **29.07** | **0.778** |

A 기준선은 이전 입면 지연의 중앙값이며, 이력이 없으면 해당 학습 부분의 중앙값을 사용했다. B 기준선은 학습 부분의 평균 점수다. XGBoost 설치가 가능한 배포판을 현재 환경에서 확보하지 못해 scikit-learn Gradient Boosting을 사용했다.

B에서 입력 6개 MLP는 0.778점, 수면 구간 길이를 제거한 MLP는 0.823점이었다. 5개 변수 모델 전체 중에서는 Random Forest가 가장 낮은 0.821점이었다. 두 구성은 같은 행과 참가자 분할에서 비교했다.

## 3. 최종 평가

교차검증으로 모델과 설정을 확정하고 전체 MeLiDos Train에서 다시 학습한 뒤 평가했다. 국내 마지막 7일은 매일 이전까지의 실제 일지를 사용할 수 있는 조건이다.

| 모델·평가 자료 | 인원 / 기록 | 선택 MLP MAE | 기준선 MAE | MLP−기준선 차이 (95% 구간) |
|---|---:|---:|---:|---:|
| A · MeLiDos | 37 / 259 | 38.14분 | 40.91분 | −2.78분 (−7.03~+1.97) |
| A · 국내 마지막 7일 | 49 / 343 | 20.25분 | 20.06분 | +0.19분 (−1.26~+1.69) |
| A · 국내 전체 | 49 / 1,372 | 21.31분 | 21.21분 | +0.10분 (−0.97~+1.30) |
| B · MeLiDos | 37 / 259 | 0.700점 | 0.750점 | −0.050점 (−0.098~+0.004) |

95% 구간은 참가자를 10,000회 짝지어 재표집해 계산했다. A는 국내 마지막 7일에서 RMSE가 기준선의 36.17분에서 34.09분으로 낮아졌지만, 10분 이내 비율도 60.6%에서 40.5%로 낮아졌다. 국내 자료에서 일관된 입면 지연 예측 개선을 확인하기 어렵다. MeLiDos에서 A는 실제보다 평균 19.54분 짧게 예측했다.

B는 최종 MeLiDos에서 수면 구간 길이를 사용하지 않은 최우수 모델의 0.756점보다 낮은 0.700점을 기록했다. 차이는 −0.056점이며 95% 구간은 −0.100~−0.013점이다. 이 최종 평가 비교는 입력과 알고리즘이 모두 다르다. 동일한 MLP의 입력 비교는 위 교차검증 결과에 해당한다.

B의 점수는 관찰된 수면 구간을 입력했을 때의 예측 성능이다. 이 평가로 개인의 최적 수면 시간이나 취침 시각 추천 효과를 확인할 수는 없다.

## 4. 재현 확인

저장된 A·B 모델을 다시 불러와 최종 평가 예측값을 재현했다. 모든 이력 변수는 날짜가 더 앞선 기록만으로 별도 계산해 대조했다. 실행 방법과 파일 구성은 [실행 환경](../실행환경/실행환경%20안내.md)에 있다.
