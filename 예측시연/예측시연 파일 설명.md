# 예측시연 파일 설명

[입력예시.json](입력예시.json)은 실제 참가자 기록을 쓰지 않은 **가상 이력 3건**이다. [예측결과.json](예측결과.json)은 그 입력을 최종 저장 모델에 넣어 생성한 출력이다.

저장소 루트에서:

```powershell
python 코드/predict.py --input 예측시연/입력예시.json --output 예측시연/예측결과.json
```

입력의 `history`는 오래된 기록부터 나열한다. A로 입면 지연을 예측하고, 후보 수면 구간마다 B의 점수와 취침 시각을 계산한다. 최소 수면 구간 조건을 만족하는 후보 중 B 점수가 가장 높은 후보를 표시한다. 날짜 차이도 출력한다.

수면 구간은 입면부터 기상까지의 간격이며 밤중 각성을 포함한다. 이 출력은 모델 동작 예시로, 실제 취침 변경의 효과를 검증한 결과가 아니다. 전처리·가중치를 불러오므로 재학습은 필요 없다.
